# 部署与升级

## Windows 首次部署

1. 从 Releases 下载对应版本源码 ZIP，解压到可写目录，例如 `D:\VideoTranslator`。推荐用发布版本；`main` 是持续更新的开发分支。
2. 安装 **Python 3.12 64 位**（包含 Tcl/Tk），安装时勾选加入 PATH。可在终端运行 `winget install --id Python.Python.3.12 --exact`。
3. 安装 FFmpeg：`winget install --id Gyan.FFmpeg --exact`。也可自行取得可信的 FFmpeg，将 `ffmpeg.exe`、`ffprobe.exe` 放到 `tools/bin/`，无需修改 PATH。
4. YouTube 推荐安装 Node.js LTS：`winget install --id OpenJS.NodeJS.LTS --exact`。安装工具后重新打开终端。
5. 双击 `install-local.bat`（或「安装或更新依赖.bat」）。安装器检测 Python 版本、创建 `.venv`、安装依赖、运行依赖检查，并首次创建 `.env`。已有 `.env` 不会覆盖。最后检查环境；尚未填写配置时提示未就绪属于正常情况。
6. 编辑 `.env`，填写翻译 API 密钥、HTTPS Base URL 和模型。默认模型为 `qwen-mt-flash`。不要把配置文件发送给别人。
7. 双击 `check-local.bat` 检查环境，再双击 `start-local.bat`（或「启动视频翻译台.bat」）。网页地址是 http://127.0.0.1:8501。

安装时需要网络；依赖和首次识别模型下载可能较大。发布包包含源码，不包含 Python、FFmpeg、模型或离线依赖，不能直接作为免安装 EXE 使用。
安装器不主动安装系统软件；上面的 WinGet 命令由用户选择执行。

## 日常使用

- 本地已下载的视频：在网页顶部展开本地导入，填写完整路径或上传文件。
- 在线视频：侧栏填写账号/频道/视频链接并扫描，再手动选择处理。
- 字幕输出：选择独立字幕文件，或进入审核区预览、调整样式后烧录。
- 网页和管理器显示版本号。关闭网页不会停止后台服务，停止请用停止入口。
- `.env` 保存配置；`local-data/` 包含数据库、审核稿、模型、凭证和全部输出。请自行备份。

## 升级：发布 ZIP（推荐）

1. 等当前任务结束，使用停止入口停止旧版本服务。
2. 备份旧目录的 `.env` 和整个 `local-data/`。空间不足时至少备份数据库、审核稿和凭证，并单独保存视频。
3. 将新版本解压到**新目录**，复制备份的 `.env` 和 `local-data/` 到新目录；不要复制旧 `.venv`。
4. 运行安装入口、环境检查和启动入口。验证正常后再处理旧目录。
5. 数据库升级可能不向后兼容；回退时使用旧版本程序和升级前的数据备份，避免直接把新数据库交给旧版本。

## 升级：Git 克隆

停止服务并备份 `.env` 和 `local-data/`，在工作区干净、分支为 `main` 时运行 `update-local.bat`。
升级器检查本项目是否在运行，拒绝覆盖本地代码改动，只允许从项目官方 origin 进行快进拉取，然后安装依赖和检查环境。
代码拉取成功但安装失败时会保留错误并停止，不会启动服务；解决网络或依赖问题后重新执行安装入口。
Git 更新跟随 `main`；要使用固定版本，请采用发布 ZIP 或手动检出对应 tag。

## 可选 NVIDIA 加速

运行 `install-local.bat --gpu` 安装可选 NVIDIA 运行库，然后在网页选择自动/CUDA。
显卡驱动和硬件需兼容，不能保证全部 NVIDIA 设备都可运行；默认安装使用 CPU 也能完成识别。
安装或更改依赖前需停止本项目服务。FFmpeg 烧录仍使用 CPU。

## 排错

- Python 未找到：安装 Python 3.12 x64，关闭并重新打开终端；已有其他版本的 `.venv` 请先备份并改名，再安装。
- 缺少 FFmpeg：检查 `check-local.bat`；确认两个 EXE 位于同一目录，或放到项目 `tools/bin/`。
- 翻译服务未配置：填写 `.env` 后重新检查；诊断不会打印密钥。
- 8501 被占用：先停止旧目录的服务；启动器不会关闭其他应用占用的端口。
- 首次下载模型慢：保持网络通畅；已缓存模型位于 `local-data/models/`。
- 导入大视频：使用本机文件路径，避免网页上传大小限制。
- 运行日志：`local-data/logs/`；单个视频的烧录错误查看其输出目录下 `ffmpeg.log`。

仅支持本机访问，不提供公网账户认证；无需进行端口转发。
